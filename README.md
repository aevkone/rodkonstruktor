# Летопись рода — витрина

Статическая часть сервиса «Летопись рода»: лендинг, пример сайта семьи (вымышленная семья Соколовых) и черновики документов.
Сам сервис (редактор, публикация сайтов семей) работает на отдельном сервере.

Адрес: https://aevkone.github.io/rodkonstruktor/

Собрано скриптом tools/build_pages.py из основного проекта. Шрифты — SIL OFL 1.1.
